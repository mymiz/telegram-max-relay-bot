# Telegram → MAX: передача кода входа

Бот в **Telegram** для сценария:

1. **Владелец** регистрирует номер, привязанный к MAX (`/register`).
2. **Вы (админ)** запускаете вход в MAX на этот номер и пишете боту `/request +7999...`.
3. **Владелец** добровольно присылает код из SMS/MAX.
4. Бот пересылает код **вам** в Telegram.

Бот **не** запрашивает код в MAX сам — только связывает владельца и админа.

## Запуск в облаке (рекомендуется)

Если с ПК нет доступа к Telegram API — деплой на сервер:

**[DEPLOY.md](DEPLOY.md)** — пошагово: GitHub + Railway (Docker, переменные, диск для данных).

## Установка на компьютере

```bash
cd telegram-max-relay-bot
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

1. Создайте бота у [@BotFather](https://t.me/BotFather), вставьте токен в `TELEGRAM_BOT_TOKEN`.
2. Запустите `python bot.py`, напишите боту `/myid`, укажите ID в `ADMIN_USER_IDS`.
3. Перезапустите бота.

### Если ошибка «Cannot connect to api.telegram.org»

Telegram API с вашего ПК недоступен (блокировка, firewall, нет VPN). Варианты:

1. Включите **VPN** и снова запустите `python bot.py`
2. Или укажите локальный прокси в `.env`:

```env
TELEGRAM_PROXY=http://127.0.0.1:10809
```

(порт подставьте из настроек вашего VPN/прокси-клиента)

## Команды

### Владелец

| Команда | Действие |
| --- | --- |
| `/register` | Привязать номер (кнопка контакта или текст) |
| `/code 123456` | Отправить код при активном запросе |
| `/decline` | Отказаться передавать код |
| `/myid` | Показать Telegram ID |

Можно отправить код просто цифрами в чат, когда есть активный запрос.

### Админ

| Команда | Действие |
| --- | --- |
| `/owners` | Список владельцев и номеров |
| `/request +79991234567` | Запросить код у владельца этого номера |
| `/cancel` | Отменить свой запрос |
| `/myid` | Ваш ID |

## Ограничение владельцев

В `.env` можно задать:

```env
OWNER_USER_IDS=111111111,222222222
```

Тогда регистрироваться смогут только эти Telegram ID.

## Данные

Файл `data/store.json` — номера и активные запросы. Не коммитьте в git (папка `data/` в `.gitignore`).

## Безопасность

- Храните `.env` и `data/store.json` в секрете.
- Передача кода возможна только после явного запроса админа; владелец может отказать (`/decline`).
- Используйте только с согласия владельца аккаунта MAX.
